# Topic folder index

The original 26 topic folders remain the progress-tracking baseline. Additional modules from the curriculum review are mapped into the nearest topic folder and cross-referenced in `CURRICULUM-REVIEW-AND-EXPANSION.md`.

- `01-Database-Fundamentals/` — DB concepts, DBA role, OLTP/OLAP, ACID, normalization, keys and constraints.
- `02-PostgreSQL-Installation/` — Linux prerequisites, sizing, package management, installation and systemd.
- `03-PostgreSQL-Architecture/` — process model, memory, WAL, MVCC, background processes and storage.
- `04-psql-and-pgAdmin/` — psql, pgAdmin, DBeaver and DBA utilities.
- `05-SQL-Fundamentals/` — DDL/DML/DQL/DCL/TCL and practical SQL.
- `06-Advanced-SQL/` — joins, CTEs, windows, routines, triggers, JSON and extensions.
- `07-Database-Schema-Tablespace/` — database/schema/object/tablespace administration.
- `08-User-Role-Privileges/` — RBAC, GRANT/REVOKE and default privileges.
- `09-PostgreSQL-Configuration/` — parameter management and safe configuration changes.
- `10-Authentication-Connectivity/` — HBA, SCRAM, TLS, networking and app connectivity.
- `11-Transactions-Concurrency/` — ACID, MVCC, isolation, locks and deadlocks.
- `12-Storage-Maintenance/` — vacuum, autovacuum, bloat, statistics and wraparound.
- `13-Backup-Restore/` — logical/physical backups and restore drills.
- `14-WAL-PITR/` — archiving, WAL and point-in-time recovery.
- `15-Indexing-Query-Optimization/` — index design and execution plans.
- `16-Performance-Tuning/` — workload analysis, memory, I/O, WAL and pooling.
- `17-Monitoring-Alerting/` — logs, exporters, dashboards, alerting and capacity.
- `18-Streaming-Replication/` — physical replication and replication-slot operations.
- `19-Logical-Replication/` — publisher/subscriber and migration patterns.
- `20-High-Availability/` — Patroni, fencing, failover, failback and load balancing.
- `21-Security-Auditing/` — TLS, RLS, pgaudit and security governance.
- `22-Partitioning/` — partition design and lifecycle management.
- `23-Upgrades-Migration/` — major/minor upgrades and data migration.
- `24-Production-Troubleshooting/` — incidents, RCA and operational runbooks.
- `25-Automation-Scripting/` — Bash/SQL/Python, scheduled jobs and safe automation.
- `26-Final-DBA-Project/` — integrated production-style project and interview assessment.

Added coverage is not considered completed merely because a folder exists. Update the topic README only after teaching and validating its practical.
